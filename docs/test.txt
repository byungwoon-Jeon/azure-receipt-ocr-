Google 공식 Standard 가격표상 Gemini 3 Flash Preview의 Global 입력은 $0.50/1M tokens이고 출력(response + reasoning)은 $3.00/1M tokens야. 

미디어 기본 설정에서는 Gemini 3 기준 이미지가 약 1,120 tokens, PDF가 약 560 tokens 수준으로 처리되며 PDF의 텍스트는 추가될 수 있어. 그래서 위에서는 PDF 변환, 다페이지 문서 등을 감안해 미디어/문서 부분을 4K로 넉넉하게 잡은 거야.

2026년 예상 비용: 약 6,000만 원
올해 소급 데이터 89만 건 + 정상 연간 예상 데이터 32만 건으로 총 121만 건을 처리하는 것으로 산정. DB 1건당 복합파일 및 첨부파일 처리를 고려해 평균 3회 API 호출, 호출당 Input 12K / Output·Reasoning 2.1K tokens를 적용함.
소급 적용분 약 4,400만 원 + 정상 연간분 약 1,600만 원 = 총 약 6,000만 원.

그리고 2027년부터 소급분이 없다면 약 1,600만 원/년이라는 것도 같이 말하면 좋아. 그러면 팀장님 입장에서 “6천만 원이 매년 드는 건가?”라는 오해를 바로 막을 수 있어.

참고로 토큰 단가를 아주 쉽게 말하면 입력 1천 토큰 ≈ 0.67원 / 출력·추론 1천 토큰 ≈ 4.02원이야. 출력 토큰이 입력보다 6배 비싸기 때문에, 실제 운영비 관리에서는 프롬프트보다 불필요한 reasoning/output을 줄이는 것도 중요해.
