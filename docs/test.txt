안녕하세요.

Upstage 기반 문서 데이터 추출 개발 건을 인수인계받아 잔여 개발 및 운영팀 이관을 진행할 예정입니다.

현재 전달받은 문서를 통해 문서 데이터 추출 요건과 문서 유형별 추출 항목은 확인하였습니다.
이후 개발 및 테스트, 배포, IDP 연동까지 원활하게 진행하기 위해 아래 자료와 내용에 대해 추가로 전달 및 설명 부탁드립니다.

1. 샘플 및 테스트 데이터

* 기존 Agent에서 정상 처리되는 Invoice 샘플
* FedEx 관련 정상/오류 발생 샘플
* 가능하다면 각 샘플에 대한 기대 추출 결과(Ground Truth)
* 현재 테스트에 사용 중인 데이터 및 테스트 케이스

2. 기존 Agent 관련

* 현재 운영/개발 중인 Agent의 전체적인 구성 및 처리 방식
* 사용 중인 Prompt, Extraction Schema, Model 및 주요 설정
* 기존 Agent의 적용 대상 문서와 처리 범위

3. FedEx 전용 Agent 관련

* FedEx 전용 Agent를 별도로 구성하게 된 배경 및 기존 Agent와의 차이
* 현재까지 개발된 범위 및 남아 있는 개발 항목
* FedEx 문서를 별도 Agent로 Routing하는 방식 및 전체 처리 흐름

4. FedEx 오류 및 해결 진행 현황

* 현재 발생 중인 오류 현상
* 현재까지 분석된 원인
* 지금까지 시도한 해결 방법 및 각 시도 결과
* 현재 진행 중인 해결 방향
* 아직 해결되지 않은 이슈 및 고려 중인 사항

5. 테스트 방법 및 완료 기준

* Agent 수정/개발 후 테스트하는 방법
* 사용 중인 테스트 환경 및 테스트 절차
* 테스트 성공/실패 판단 기준
* 기존 정상 문서에 대한 Regression Test 여부 및 방법

6. Agent 배포 절차

* 개발/수정된 Agent를 테스트 및 운영 환경에 반영하는 절차
* Agent 생성, 수정, Publish/배포 방법
* 배포 시 필요한 권한 및 계정
* DEV/TEST/PROD 환경이 구분되어 있다면 각 환경별 적용 절차

7. IDP팀 연동 절차

* 신규/수정 Agent에 대해 IDP팀 연동을 요청하는 방법
* 요청 시 전달해야 하는 정보
* 관련 담당자 및 요청 채널
* IDP 연동 후 End-to-End 테스트 방법 및 확인 절차

8. 운영 및 장애 대응 관련

* Agent 호출 및 처리 결과 확인 방법
* Log 확인 위치 및 주요 확인 항목
* 오류 발생 시 Retry/재처리 방법
* RPA, IDP, Upstage 영역별 장애 구분 및 대응 방법

9. 기타 환경 및 관리 정보

* Agent 설정 및 Prompt/Schema 등의 버전 관리 방식
* 관련 소스 또는 설정 정보 관리 위치
* API Key 및 Secret 등의 관리 방식
* 개발 및 운영에 필요한 접근 권한

기존에 작성된 문서가 있는 항목은 해당 자료를 전달 부탁드리며, 별도 문서가 없는 부분은 인수인계 과정에서 설명해 주셔도 괜찮습니다.

특히 FedEx 관련 오류의 경우 현재까지 진행된 분석 내용과 시도했던 방법을 확인할 수 있으면 이후 개발을 이어가는 데 도움이 될 것 같습니다.

확인 부탁드립니다.
